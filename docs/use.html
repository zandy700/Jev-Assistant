Reads the chat you have open and suggests three replies. It never sends anything.

Key

Set up once

  1. Save your OpenRouter key Stays in this browser only. Saved in this browser.

    Create one at openrouter.ai/keys and set a spending limit.

  2. Drag the Jev tag to your bookmarks bar It is at the top of this page.
  3. Open a chat and click the bookmark Instagram, WhatsApp Web, Snapchat Web, or Google Messages. Your replies show up here.
